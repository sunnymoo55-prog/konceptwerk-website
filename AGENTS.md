# AGENTS.md

## Goal
Maintain a refined, warm, architectural Koncept Werk website.

## Rules
- Static HTML/CSS/vanilla JavaScript unless explicitly asked to migrate.
- Keep global styles in `assets/styles.css` and behaviour in `assets/main.js`.
- Preserve responsive layouts.
- Do not commit secrets or credentials.
- Keep copy concise and client-friendly.
- Test navigation and mobile layout after changes.
