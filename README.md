# Koncept Werk website

Redesigned static website for Koncept Werk.

## Local preview
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.

## Structure
- `index.html` Home
- `about.html` About
- `services.html` Services
- `career.html` Careers
- `blog.html` Journal
- `contact.html` Contact
- `assets/styles.css` Global styling
- `assets/main.js` Interactions

## Before launch
Confirm business contact details, connect the demo forms to a real backend, add legal/privacy pages, and confirm rights to all referenced images.
